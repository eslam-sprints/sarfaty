# صرفتي

تطبيق Flutter عربي لتتبع المصروفات وإدارة بطاقات الكريديت.

> التطبيق ما زال قيد التطوير.

## النسخة الأولى

- لوحة رئيسية للمصروفات والرصيد ومستحقات البطاقات.
- تسجيل مصروفات الكاش والكريديت وتصنيفها.
- إدارة البطاقات ونسب الاستخدام وتسجيل السداد.
- تنبيهات داخل التطبيق لمواعيد السداد وحدود 70% و90%.
- ملخص شهري للكاش والكريديت وأعلى تصنيف.
- صفحة لكل المعاملات مع فلاتر الدفع والتصنيف والتاريخ والبطاقة.
- سداد كامل أو جزئي للبطاقات مع ظهور السداد ضمن المعاملات والملخص.
- حفظ محلي دائم ونسخ احتياطي JSON قابل للنقل بين الهواتف.
- وضع داكن مع خيارات تلقائي حسب النظام أو فاتح أو داكن من الإعدادات.
- قاعدة بيانات SQLite محلية منظّمة، مع تخزين القيم المالية بالقروش لتفادي أخطاء الكسور.
- تحميل تدريجي للمعاملات مع الفلاتر والإجمالي وعدد النتائج.
- شاشة بداية ومقدمة تعريفية تظهر عند أول تشغيل.
- واجهة عربية RTL، ويبدأ التطبيق فارغاً لتسجيل بيانات المستخدم الحقيقية.

## التشغيل

تم التحقق من المشروع باستخدام Flutter 3.47.2 وDart 3.13.2.

```bash
flutter pub get
flutter run
```

## التحقق

```bash
flutter analyze
flutter test
flutter build apk --release
```

## النسخ الاحتياطي ونقل البيانات

من تبويب **الإعدادات** اختر **تصدير البيانات** لإنشاء ملف JSON ثم احفظه أو شاركه. على الهاتف الآخر افتح **الإعدادات ← استيراد نسخة احتياطية** واختر الملف؛ سيعرض التطبيق تأكيداً قبل استبدال البيانات الحالية. احتفظ بالملف في مكان آمن لأنه يحتوي على بياناتك المالية.
